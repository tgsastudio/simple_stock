# Stock TW

輕量化 Windows 即時看盤 Dashboard 軟體（支援台股與美股），以純原生 Rust (`eframe` / `egui`) 開發。

## 特色
- **極致輕量與省電**：單一原生執行檔約 **3.3 MB**（無需安裝 .NET / Java / Python / 瀏覽器核心），事件驅動渲染待機 CPU 接近 0%。
- **免登入即時報價**：
  - 台股（上市 / 上櫃 / ETF）：優先串接證交所 / 櫃買中心公開即時 API 批次查詢，並具 Yahoo Finance 自動備援。
  - 美股（NASDAQ / NYSE / ETF / 指數）：串接 Yahoo Finance 公開報價端點。
- **三種介面形態一鍵切換與完整狀態記憶**：
  - **標準模式**、**精簡側邊條模式**、**桌面透明浮動小工具**（無邊框、透明度 25%–100% 可調、支援視窗置頂）。
  - 自動記憶各模式的視窗大小與螢幕位置、上次所在分頁（全部 / 台股 / 美股）與排序方式。
- **刷新頻率與智慧省電**：
  - 提供 `5 秒` / `15 秒` / `30 秒` / `60 秒` / `手動` 五種刷新策略。
  - 內建雙市場開盤時段感知（休市自動停止輪詢）、視窗最小化暫停刷新、網路異常自動退避。
- **自選股與持股收益管理**：
  - 支援直接輸入代碼或線上關鍵字搜尋加入，並可設定每檔股票的 **持有數量** 與 **持有成本**（點擊「持股」按鈕、雙擊卡片或右鍵選單皆可編輯）。
  - 依即時現價自動計算單檔與總投資組合（TWD / USD 分開統計）的 **收益金額** 與 **收益比例 (%)**。
  - 支援滑鼠拖曳排序（`☰`）與右鍵排序。
- **多語系介面與完整安裝/升級/解除安裝**：
  - 軟體與 Windows 安裝介面皆支援 **繁體中文 / English**（預設跟隨系統語言）。
  - 支援舊版覆蓋升級、解除安裝時可選擇保留或刪除已儲存資料，以及內建 GitHub Release **檢查更新** 功能。
- **加密儲存安全性**：
  - 自選股與持股成本透過 **Windows 原生 DPAPI (`CryptProtectData`) + 應用程式專屬熵值** 加密儲存於 `config.dat`，防止其他程式或使用者讀取。

## 建置與打包（開發者）
```powershell
# 編譯 Release 最佳化版本
cargo build --release

# 使用 Inno Setup 打包 Windows 安裝檔（輸出至 dist/）
ISCC.exe installer\simple_stock.iss
```
