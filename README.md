# simple_stock

輕量化 Windows 即時看盤 Dashboard 軟體（支援台股與美股）。

## 特色規劃
- **極致輕量**：純原生 Rust (`eframe`/`egui`) 開發，免登入、低記憶體、省電。
- **台美股整合**：支援台股（上市/上櫃/ETF）與美股即時報價批次抓取。
- **三種介面形態**：標準 Dashboard、精簡側邊條、桌面透明浮動小工具（置頂/透明度可調）。
- **智慧省電刷新**：提供多種刷新頻率（5s / 15s / 30s / 60s / 手動），並具開盤時段與視窗狀態感知。
- **自選股管理**：本機 JSON 儲存、支援拖曳排序與市場篩選。
